# ostravanne.com

The Heura Studio by Ostravanne home page. It's one static page (`index.html`) served by GitHub Pages at https://ostravanne.com.

- `index.html`: the page (HTML and CSS only, no JavaScript)
- `favicon.ico`, `favicon-32.png`, `icon-512.png`, `apple-touch-icon.png`: the tab and home-screen icons
- `CNAME`: tells GitHub Pages to serve the site at ostravanne.com
